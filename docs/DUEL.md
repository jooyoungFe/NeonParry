# 듀얼

기존 게임의 캐릭터·바이러스·경기장·패링 효과를 그대로 사용하여 각자 코어를 지키고 상대를 공격합니다. 별도 전투 화면을 만들지 않고 원래 렌더러를 사용합니다. 쉬움 난이도의 이동 속도와 패링 판정을 적용합니다.

**시간제한은 없습니다.** 취약률이 100%가 되면 패배하며, 같은 시각의 공격으로 둘 다 100%가 되면 무승부입니다. 회복·피격 경직·시간에 따른 강제 피해는 없습니다.

## 시작과 조작

`npm run dev:duel` → `http://127.0.0.1:8000` → **Play → Duel / 듀얼**.

- **랜덤 매칭:** 같은 서버에서 대기하는 사람 중 상대를 찾습니다. 둘이 연결되면 자동으로 3초 뒤 시작합니다. 대기 중 취소할 수 있습니다.
- **친구 초대:** 방 만들기 → 상대가 코드로 참가 → 양쪽 준비 후 시작합니다.
- **CPU 연습:** 서버 없이 입문·대등·숙련 상대와 연습합니다.

방향키/WASD로 패링하고 Shift + 방향키/WASD로 공격합니다. 기존 스킬 버튼 또는 Space로 공격을 선택한 뒤 방향을 입력할 수도 있습니다. 공격 한 번 후에는 수비로 돌아옵니다. 터치는 기존 경기장 구역 탭으로 패링, 그 구역의 세로/가로 방향 쓸기로 공격합니다. 위쪽 공격은 상대 화면 위쪽에서 접근합니다.

## 규칙

| 항목 | 규칙 |
| --- | --- |
| 승패 | 취약률 100% / 같은 시각 쌍방 100%는 무승부 |
| 연속 적중 피해 | 15 → 20 → 25%p, 이후 최대 25%p |
| 연속 적중 초기화 | 상대가 내 공격을 한 번 패링하면 초기화 |
| 공격 에너지 | 최대 3, 시작 2, 1.8초당 1 자연 충전 |
| 기본 공격 | 에너지 1 소비 / 공격 간격 최소 350ms |
| 공격 이동 | 원래 바이러스와 같은 2,200ms / 같은 수비자 도착 간격 최소 520ms |
| 패링 판정 | 기존 쉬움과 같은 ±360ms / 방향별 간격 300ms |
| 정밀 패링 | 기존 쉬움과 같은 ±100ms / 공격 에너지 +0.5 |
| 회복·경직·라운드 제한시간 | 없음 |

공격이 판정 지점을 지난 뒤에도 패링 창 끝까지 기회가 있어 피해는 도착 361ms 뒤 확정됩니다. 연속 공격은 도착 시간을 예약하여 대응 간격을 확보합니다. 자원이 부족하면 공격을 기다리지만 수비는 계속 가능합니다.

상대가 계속 놓치면 다섯 번 적중으로 끝납니다. 실력이 비슷하면 서로 패링하며 공방이 길어집니다. 정밀 패링은 반격 자원을 주고, 일반 패링도 상대의 연속 적중 보너스를 끊습니다. 이 수치는 첫 플레이테스트 기준이며 실제 두 사람의 적중률·정밀 패링 비율·경기 길이를 보고 조정합니다.

## 온라인 판정과 서버

CPU 연습은 로컬, 온라인은 서버가 같은 공유 규칙 엔진을 실행합니다. 클라이언트는 공격·수비 방향만 전송하며 에너지·도착 예약·패링·피해·승패는 서버가 결정합니다. 플레이어가 보낸 시각·점수·피해는 판정에 사용하지 않습니다.

상태는 인증된 SSE로 약 33ms마다 갱신됩니다. 화면은 서버 시각에 맞춰 움직이며 왕복 지연을 측정해 표시 시점을 조정하지만 서버의 과거 상태를 되돌리는 보정은 제공하지 않습니다. 지연이 크거나 불안정한 연결에서는 패링에 영향이 있습니다.

다른 사람과 대전하려면 두 사람 모두 같은 공용 서버를 사용해야 합니다. 랜덤 매칭은 그 서버의 대기자 중에서 고르며 실력 등급·지역을 구분하지 않습니다. [서버 실행 안내](SERVER.md)를 참고하세요.

연결 단절 후 15초 안에 복귀하지 않으면 기권패이며 직접 나가기도 기권입니다. 친구방은 종료 후 양쪽이 다시 준비하면 재대결합니다. 랜덤 매칭은 종료 후 다음 상대 찾기로 다시 대기합니다. 새로고침 후 토큰 복구·영구 전적·랭킹은 제공하지 않습니다.
